Comment lire ces chiffres

CTL (forme) : charge moyenne des 42 derniers jours. ATL (fatigue) : moyenne des 7 derniers jours. TSB (fraîcheur) = CTL − ATL : négatif quand on charge, positif quand on récupère.

Calculé sur le Strava Relative Effort, un proxy et non un TSS : les valeurs ne sont pas comparables à un PMC standard, les seuils sont indicatifs.
